# aichatt 编码 Agent 增强方案

一句话：让 agent 从「盲写代码」升级为「写完自己检查、自己修」。分四期，参考 ZCode 源码的成熟设计。

## 一期：验证闭环（最优先）

**1.1 语法批改（服务端，半天）**
- 新建 `src/lib/code/syntax-check.ts`：TS/JS 用已有的 typescript 编译器查语法错误，JSON 用 JSON.parse，全语言检测 markdown 围栏残留，HTML 只查明显未闭合标签（宁漏勿误报）
- `write-code-tool.server.ts` 保存前调用：有硬错误 → 返回「语法错误(行x列y)：…请修正后重新调用」，模型在同一轮自己改；软警告不阻塞，附在结果里

**1.2 preview_check 预览验证工具（核心，1-1.5 天）**
AI 写完 HTML → 自己调 preview_check → 前端渲染页面并收集 console 报错 → 发回给 AI → AI 修复 → 再查，全程无需用户出手。
- 新建 `src/lib/ai/preview-check-tool.ts`（无 execute 客户端工具，仿 code-edit-tool.ts）：入参 `{docId?}`，缺省查当前打开文档
- `CodeEditor.tsx` iframe：srcDoc 头部注入捕获脚本（覆写 console.error / window.onerror → postMessage 上报，sandbox 无 allow-same-origin 所以只能 postMessage，父页面按 source 字段校验）；预览工具条加错误角标 + 「把报错发给 AI」按钮（复用现有 code-ask-ai 事件桥）
- ChatPanel onToolCall 加分支：自动打开面板 → 渲染等 2.5s 静默期（上限 8s）→ 回填 `{ok, errorCount, errors(≤20条)}`
- 接线六件套：route.ts（注入闸门与 write_code 相同、stopWhen 加名）、ChatPanel（自动续跑判据加名）、ToolCallCard 卡片。Web 端同样可用（不依赖 Tauri）

**1.3 exec 放宽（Rust，需重编译桌面端，半天）**
- `lf_exec` 加 `timeoutMs` 参数，范围 1s-600s 默认 30s（ZCode 默认 120s/上限 600s，保守起步）；输出上限 8KB→32KB（拆开三处共用的常量，overview/search 不变）；失败文案加「可传更大 timeoutMs 重试」指引
- 不做持久终端会话（ZCode 也没有）

## 二期：code_edit 片段编辑（照抄 ZCode Edit，1 天）

- schema 改为：`docId + old_text(片段) + new_text(片段) + replace_all?`；old_text 等于全文时兼容原行为
- 前端执行：取当前文档内容（面板开着用编辑器实时值，否则走已有的 GET /api/code/docs/[id]）→ 定位 old_text：0 处报「未找到」、多处报「N 处匹配，请加长片段或 replace_all」（ZCode 错误文案中文化）→ 唯一命中才替换 → 走现有 Diff 审查
- Diff 左侧从「AI 转述的原文」变为「文件真实当前内容」，更可靠
- 匹配只做两级（精确 → 逐行 trim 精确），模糊回退暂不做

## 三期：动态步数（半天）

- stopWhen：编码场景（代码面板开 / 本地文件授权）步数上限 5→10，其余不变
- 顺带修复：code_edit / preview_check 目前不在悬空调用保护里
- prompt 追加交付纪律：「能验证的先验证再收尾，失败如实说，不谎报成功」

## 四期：工作区记忆（1 天）

- 客户端组装快照：lf_overview 目录树(≤4KB) + 工作区根 AGENT.md(≤6KB)，随请求上报（仿 localFilesEnabled 的 body getter 模式，零数据库迁移）
- 服务端注入 system：「工作区快照（可能滞后，改文件前先核实）」
- prompt 告知模型：「项目约定建议写入 AGENT.md，下次会话自动生效」→ 手写约定 + 自动快照双通道（ZCode 的 AGENTS.md + memory 机制平移）

## 实施顺序与验证

顺序：1.1 → 1.3 → 1.2 → 二期 → 三期 → 四期。每期完成 `npm run build`（Rust 部分加 `cargo check`），手工验证：①坏 TS 被打回自纠 ②写 HTML 自动验证、报错后修复 ③改一行 diff 只含目标区域 ④跑 40s 命令不超时 ⑤快照注入后 AI 能答项目结构。

## 明确不做

持久终端、AI 截图回喂、多文件网页预览、模糊匹配回退、子代理体系——记录为后续方向。
